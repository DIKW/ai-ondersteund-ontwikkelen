## Rol in de bron

Claude Code is het product waarop Anthropic's artikel de voorbeelden van lusvormen baseert. Het artikel onderscheidt handmatig gestarte turn-based loops, goal-based loops met expliciete stopcriteria, time-based loops en proactive loops die door een event of schema starten. Het benadrukt ook verificatie, begrenzing van iteraties en bewaking van tokengebruik.

Dit is een productgerichte beschrijving uit één bron, geen volledige of blijvende specificatie van Claude Code. De bronmetadata noemt als publicatiedatum alleen "Jun 30", zonder jaar; controleer actuele productdocumentatie voor versiegevoelig gedrag.
